# Nour Colab guide

Open `Nour_Deep_Learning_Colab.ipynb` in Google Colab.

1. Choose **Runtime -> Change runtime type -> GPU**.
2. Run cells from top to bottom.
3. Sign in to Google Drive when prompted.
4. Checkpoints and metrics go to `MyDrive/NourML`.
5. Rerunning the notebook resumes from the latest checkpoint.

The laptop sandbox remains the persistent local learner and coordinator.
